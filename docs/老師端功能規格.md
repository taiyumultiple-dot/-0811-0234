# 老師端：逐題批改與全班學習總覽

> 規格寫於 2026-08-12。需求來自使用者，設計已定案，尚未實作。
> 資料結構已經探過，下面寫的都是查證過的現況，不是猜測。

---

## 需求

1. 老師要能看到**每一個學生**在**每一個單元**的**每一題**寫了什麼，並且能**逐題回覆**。
2. 「學習紀錄」在老師登入時要改成**全班同步狀況**的總覽（學生登入時維持現在的個人版）。

---

## 現況：底子有一半

| 已經有 | 位置 |
|---|---|
| 逐題的學生作答 | `StudentSubmission.unitWorksheets[unitId].answers`（`Record<questionId, any>`，`src/types.ts:126`） |
| 教師模式與學生切換下拉 | `UnitStudyView.tsx:373` |
| 老師批改分頁 | `UnitStudyView.tsx:432` |
| 整單元的回饋 | `unitWorksheets[unitId].feedback`（`Feedback`：comments / gradedBy / gradedAt / badges / score） |

**缺的兩件事**

- 回饋是「整個單元一則」，**沒有辦法針對某一題**回覆。
- 老師一次只能看**一個學生的一個單元**，沒有跨學生的並排檢視。

---

## 設計

### 一、逐題回覆

`src/types.ts` 的 unitWorksheets 那一格加上 `replies`：

```ts
unitWorksheets?: Record<string, {
  answers: Record<string, any>;
  submitted: boolean;
  submittedAt?: string;
  feedback?: Feedback;              // 保留：整單元的總評
  replies?: Record<string, {        // 新增：逐題回覆，key 是 questionId
    text: string;
    by: string;                     // 老師名字
    at: string;                     // ISO 時間
  }>;
  readingProgress?: number;
}>;
```

**學生端**：每一題答案底下多一塊老師回覆（沒有就不顯示）。
**老師端**：`UnitStudyView` 的批改分頁改成「**逐題檢視**」——
選一題，就看到全班每個人對這一題寫了什麼並排列出，一則一則回。
比現在「切一個學生看整份」快得多，也符合老師真的批改的動線。

整單元總評保留，兩者並存：逐題回覆給細節，總評給整體。

### 二、學習紀錄（老師版）

`LearningRecordTab` 依 `currentUser.role` 分岔：

- **學生** → 現在這一頁（個人統計、趨勢圖、課本完成度），不動。
- **老師** → 換成**全班一覽表**：
  - 一列一個學生，橫向是六個單元
  - 每格顯示完成度，並用色塊標狀態：未開始／進行中／已提交待批改／已批改
  - **「已提交但還沒回」要有紅點**，這是老師每天真正要看的東西
  - 點任一格 → 直接跳到那個學生的那一單元的批改畫面
  - 上方一排總計：待批改幾份、本週提交幾份、全班平均完成度

配色沿用全站的米白 `#FAF6F0` ＋磚橘 `#E65100`，不要再出現深色。
