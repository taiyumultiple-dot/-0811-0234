# 遊戲01 美術定案預覽（截圖 Demo，非正式網站程式碼）

這個資料夾放的是「幸福導航：生命地圖啟程」這一關的視覺設計稿預覽，
用來確認畫面版面、風格與互動位置——**不是正式網站使用的程式碼**，
不會影響 `src/` 底下實際運作的網站。

## 檔案說明

- `01-大廳.html`：任務地圖大廳畫面（開場的 4 個任務站 + 幸福之門）
- `02-五個任務.html`：任務1～5 的詳細畫面（分頁切換），含任務5「幸福之門」結算頁

## 這是怎麼做的

每個頁面都是把設計截圖直接當背景圖，疊上一層依座標定位、平常看不見的
可點擊區塊，點擊後用畫面下方的提示訊息（toast）做假互動回饋。
好處是能快速確認「版面、位置、感覺對不對」；缺點是背景圖只有單一固定
狀態，無法真正呈現選中/未選中的畫面變化、真實倒數計時、拖曳排序等
遊戲邏輯。

## 下一步（尚未進行）

若要把這一關真正做成可玩遊戲，需要：
1. 把畫面中的個別圖示（時鐘、天秤、鏡子、書本、鑰匙……）拆成獨立的
   去背素材圖片，而不是整頁合成好的畫面；或
2. 用簡化版插畫／CSS 重新刻版面，但邏輯（計時、拖曳、分類、計算五把
   鑰匙結果）全部改用真正的 React state 實作。

這兩個方向都還沒有動工，目前僅供設計參考。
